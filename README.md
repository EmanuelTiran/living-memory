# זיכרון חי — Living Memory

Living Memory היא אפליקציה עברית לשימור סיפורי חיים, זיכרונות ומורשת משפחתית ולהפיכתם לחוויה אינטראקטיבית מבוססת AI.

המערכת משלבת תוכן מאושר, שיחה מבוססת מקורות, קול משובט ואווטאר חי. היא אינה האדם עצמו, אינה משחזרת תודעה ואינה מציגה תוכן שנוצר ב־AI כזיכרון אמיתי ללא סיווג מתאים.

## מצב הפרויקט

נכון ל־2026-08-19 קיים vertical slice פעיל מקצה לקצה:

- הרשמה, התחברות ו־session מאובטח.
- כמה פרופילי זיכרון לכל משתמש.
- סיפורים, שאלון ביוגרפי, הקלטות ותמלילים מאושרים.
- Chat הנשען על מקורות מאושרים ומציג citations וסיווג תשובה.
- קלט קולי לשיחה ותמלולו.
- TTS כללי וכן קול אישי משובט באמצעות ElevenLabs.
- פרופילי קול ואווטאר עם הסכמה מפורשת ואפשרות ביטול.
- אווטאר D‑ID בזמן אמת עם lip sync.
- דיבור מדורג: המקטע הראשון מוכן ראשון והמקטעים הבאים מוכנים מראש.
- fallback אוטומטי לקול/אווטאר מקומי במקרה של תקלה בשידור החי.
- fallback ל־MongoDB SRV DNS ברשתות שבהן Node מקבל `querySrv ECONNREFUSED`.

בדיקת משתמש מאומתת ב־2026-08-19: תחילת דיבור סביב 8 שניות, המשך מעבר למשפט הראשון, lip sync תקין והווידאו נשאר מוצג בין המקטעים.

## טכנולוגיות

- npm monorepo עם `client`, `server` ו־`shared`.
- React 19, Vite ו־React Router.
- Node.js, Express 5, MongoDB Atlas ו־Mongoose.
- JavaScript ו־ES Modules.
- Zod, Vitest ו־Supertest.
- OpenAI עבור Chat ותמלול.
- ElevenLabs עבור קול אישי.
- D‑ID Client SDK עבור אווטאר בזמן אמת.

## דרישות מערכת

- Node.js `>=24.18.0 <25`
- npm `>=10`
- MongoDB Atlas
- מפתחות ספקים רק עבור היכולות שמפעילים

## התקנה והפעלה

מתיקיית השורש:

```powershell
npm install
Copy-Item .\client\.env.example .\client\.env.local
Copy-Item .\server\.env.example .\server\.env
npm run dev
```

האפליקציה זמינה בפיתוח ב־`http://localhost:5173` וה־API ב־`http://localhost:5000`.

אין לשתף קובצי `.env`, כותרות `Authorization`, עוגיות או refresh tokens. כאשר משתפים צילום מכלי המפתחים, מציגים רק את אזור `General` ומסתירים את `Request Headers`.

## בדיקות

```powershell
npm run check
```

הפקודה מריצה lint, בדיקות שרת ובניית Client. בבסיס הקוד שנבדק ב־2026-08-19 עברו 88 קובצי בדיקה ובהם 532 בדיקות, וגם בניית Vite הושלמה.

## מגבלות מרכזיות

- Retrieval הוא עדיין לקסיקלי ולא RAG וקטורי מלא.
- שיתוף, הזמנות וזרימת תרומות עדיין אינם שלמים.
- אחסון המדיה המקומי ותורי העיבוד אינם מתאימים עדיין לפרודקשן רב־מופעי.
- אין עדיין barge-in מלא, ניהול עלויות, audit log או מחיקה מלאה אצל כל הספקים.
- נדרשות בדיקות E2E אוטומטיות לשיחה הקולית ולשידור החי.
